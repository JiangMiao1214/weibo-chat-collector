### F1：独立账号管理页（已实现）

导航新增“账号管理”。可独立新增账号、修改名称/备注、启停，查看群数、消息数、本机凭据准备状态、各群最近采集与归档情况。提供登录与采集、查看账号消息、明确确认后清除本机凭据的入口；新增删除空账号，先预览并确认，有任何历史记录时拒绝。

停用和清除凭据保留历史；运行采集需先安全停止、扫码会话需先结束。停用停止排队任务并暂停归档，重新启用不自动恢复。清除凭据还需等待在途归档退出，不会删除其他账号的凭据。详见 [账号群聊管理](target-management.md)。

### F2：独立群聊管理页（已实现）

导航新增“群聊管理”，可按账号筛选、为无群账号新增首个群、编辑名称/备注/数字源群 ID 和启用状态。可暂留群 ID 后扫码绑定；同账号重复绑定会被拒绝。既有历史的群不能改绑另一个微博群，所属账号不能变更。

展示已入库日期、未删除消息/附件数、最近任务与归档概况；直接进入对应消息、扫码采集、归档或既有全局监控。已有日期跨度不等于完整覆盖。详见 [账号群聊管理](target-management.md)。

### F3：永久引用关系（已实现，原生字段自动接入仍有限制）

支持用户在引用上下文中查找候选、核对作者/时间/正文后再次确认，保存永久关系；已在当前列表唯一匹配的消息可从详情“管理引用关系”进入。支持解除、纠正关联，重启后保留；目标删除时不退回关联另一条同文消息。

标准化 JSON/CSV 导入可明确提供 `reply_to_source_message_id`，同事务保存关系，支持同秒和目标晚入库，并回填保留该字段的旧导入数据。明确解除后不会被历史回填擅自恢复。

**仍有限制：**只读检查现有历史库字段结构后，未发现可靠的微博群聊回复目标 ID。微博分享对象的回复 ID 不能复用为群聊引用。当前没有按未经验证字段自动建立原生引用，也不能保证所有旧引用可消歧；无永久关系的记录仍用保守文字匹配。后续如获得可靠样例，再单独实现原生采集字段接入。详见 [永久引用](permanent-references.md)。

### F4：连续上下文、多级返回及缺失原文处理（已实现）

侧栏和引用弹窗可双向追加上下文，重叠消息去重，同秒按 ID 稳定排序。每级保留 100 条，反向可取回移出消息；支持 20 层引用返回并保留每层滚动/窗口。先查询完整本地范围，未找到可明确确认后创建最多 7 天、每次 20 页的采集任务，保留启动确认、串行、断点和账号风险冷却。不能保证补回已删除/无权限原文。

### F5：独立统计仪表盘（已实现）

导航“统计仪表盘”支持账号、群、日期和回收站隔离，日/周/月趋势、活跃成员、类型、归档状态；原件按实际唯一路径计量并按类型分组。点击日期/成员进消息，点击归档状态进对应日志。正文保存与已识别媒体全部保存分开，未采集日期不当作真实零发言。

### F6：独立日志页面（已实现）

导航“操作日志”按时间、账号、群、任务、操作、结果、错误码检索；涵盖采集/归档/OCR 状态事件与页提交。可定位消息、精确重试资源、访问原始/实际失败链接、处理具体采集任务，导出脱敏 JSON。保留最近 90 天且最多 10000 条；升级前只能补状态基线，不虚构已丢失的事件历史。

### F7：OCR 图片文字搜索（已实现）

导航“图片文字搜索”，选择账号和群后显式开启历史及新增图片识别，默认关闭。只读本地已归档图片，单并发、暂停/恢复/失败重试、按账号哈希复用、独立文字/FTS 索引、回收站隔离、缩略图及消息跳转。macOS 本地 Vision 的三种字号中文印刷体基准已通过；Windows/Linux 本地 Tesseract 适配尚待实机验证，手写/斜拍/复杂图纸准确率不作保证。

完整操作、实现限制、基准与验收记录见 [F4–F7 使用说明](reader-insights-ocr.md)。

### F8：定时采集

当前任务队列负责执行已经创建的任务，不会每天自动创建采集任务；消息入库后自动排队下载附件也不等于定时采集。

- 设置账号/群、运行时间、时区、启停状态和回看范围，记录下次触发与上次结果；从成功断点确定增量边界，合理重叠并去重。
- 默认建议到点创建“待确认”任务，沿用现有人工启动机制。真正无人值守采集需要另外确认产品规则并实现，不能悄悄绕过启动确认。
- 全账号仍串行；同群已有活动任务时不重复创建。关机/睡眠漏跑后合并有界补跑，避免重启时积压任务集中请求。
- 登录失效、风控或冷却期间阻止继续触发；下一次定时不能绕过错误停止和人工恢复。后台服务需要运行，电脑休眠期间不能按时执行。
- 完成标准：重复触发、跨日时区、服务重启、漏跑、手动任务竞争与风险暂停都有明确且可测试的结果。
