成员之间是“或”，不同维度是“且”。
同时选林与陈，显示两人的发言；再选图片，显示两人的图片消息。成员数字为基础范围统计，因此不会跟着每个阅读筛选一起变小。

    一个队列
    全部账号共享一个活动位；待确认也会占位。浏览器扫码与采集中 / 待确认任务互斥。
    一页一提交
    消息、计数、页记录与游标一起提交。失败页不推进断点；运行中停止需等待安全页边界。
    错误不自动重试
    采集遇错即停。429 / 10023 / 10024 冷却 60 分钟，到期仍需人工续传并再次确认。附件归档有自己的重试规则。

    06
    
    
    操作实际作用范围需要记住
    
      
    关键词筛选当前账号 / 群 / 日期及其他已应用条件改变列表、导出和批量操作范围；也可匹配附件标题 / 地址。
    
      
    正文查找当前完整筛选结果里的正文高亮和导航，不缩小导出 / 删除范围；可以定位未加载消息。
    
      
    上下文 / 引用定位原消息同账号、同群、同删除状态忽略日期、关键词等内容筛选；主列表保留。临时定位期间禁用导出和批量操作。
    
      
    TXT 导出 / 批量操作全部当前筛选结果，包括未加载分页不是当前屏幕上的几条消息。删除 / 恢复 / 彻底删除先预览再确认。
    
      
    开启本群归档所选账号 + 所选群的全部未删除历史及后续新增不受日期、成员、类型或关键词影响；关闭弹窗不停止后台下载。
    
      
    开启 OCR本群全部未删除、已归档图片识别队列不受搜索日期限制；查询结果才按日期与回收站范围过滤。
    
      
    备份 / 恢复 / 磁盘清理全部账号的本地库与附件不是当前群的操作。恢复生成独立副本；清理只处理经确认的无引用原件等。
    
    
    
    
    “软删除”进入回收站；“彻底删除”删除数据库记录及关联元数据，仍保留磁盘原件。要释放无引用原件占用，请单独使用磁盘维护的预览与确认清理。

    PROJECT NOTES
    能力边界与阅读依据。
    根据 2026-10-20 当前工作区的代码、页面入口和功能文档整理。旧文档含历史说明，冲突处以新修订和当前实现为准。
    
    
    已经实现
    • 多账号 / 群管理、扫码绑定、时间范围采集、队列监控、停止与续传。
    • 消息阅读与筛选、TXT 导出、连续上下文、人工永久引用、有界补采集。
    • 本地附件归档、图片灯箱、校验补下载、备份恢复、磁盘清理。
    • 统计仪表盘、持久操作日志、本地图片 OCR、备用导入和回收站。
    仍有限制
    • 定时采集 F8 尚未实现。需要手动创建任务，排队后再确认运行。
    • 尚无可靠的微博原生群聊回复目标字段证据；自动文字匹配不能消歧所有旧引用。
    • 账号 B、复杂视频 / 文件、长期下载和大历史库性能仍需实机或规模验证。自动测试不代表这些均已完成。
    • 不支持完整网站镜像、第三方自动登录、DRM / 加密视频、直播与 DASH；移动端全面适配不在当前计划。
