## 已核验的源字段边界

对当前本地历史库只读检查了字段名及结构，没有输出聊天正文或凭据，也没有发送微博请求。现有群聊消息及其 annotations 中未发现可验证的被回复群消息 ID。分享链接下 `url_objects[].status.in_reply_to_status_id` 属于微博正文，不能当成群聊回复 ID；`annotations.smart_search.msg_local_id` 也没有被当成目标 ID。

因此本版不声称已恢复微博原生的全部引用关系，提供下列明确区分的机制：

| 来源 | 定位方式 | 页面说明 |
| --- | --- | --- |
| 标准化导入明确提供 `reply_to_source_message_id` | 按账号、群和目标源 ID 定位 | 按导入数据明确提供的目标源 ID 定位 |
| 用户在候选中选择并确认 | 保存精确本地目标 ID，并保留目标源 ID（若有） | 人工确认的永久关联 |
| 没有已保存关系 | 原有唯一完整文字匹配 | 完整文字唯一匹配，不是源 ID 确认 |

每条消息自己的 `source_message_id` 不是回复目标 ID。未来若获得可靠的微博字段样例，应另补采集适配器的红—绿测试后接入，不能从任意名称相似的字段推断。

## 人工确认步骤

1. 在引用块点击“查看引用原文”；已在当前列表唯一匹配的消息，可打开详情后点击“管理引用关系”。窗口仍只显示同账号、同群、同删除状态的原文与相邻消息。
2. 点击“选择并永久关联原消息”。默认找引用全文相同的候选，可输入原文关键词进一步查找；每页最多 20 条，支持前后翻页。
3. 核对作者、时间、正文和源 ID，点击“选择此原消息”。候选也允许同秒消息，但不会自动判定顺序。
4. 再点击“确认保存引用关系”。此时才持久保存，重新打开窗口后仍使用该目标，原文修正不破坏人工关联。
5. 要纠正关系，可重新选择并确认，或点击“解除永久关联”并再次确认。解除操作会持久记录，重启的历史回填不会擅自恢复。

没有候选时可换关键词或先导入原文；不会自动联网补采集。人工确认只代表用户确认，不升级为平台源 ID 证据。

## 标准化导入与历史回填

JSON 消息可显式提供以下字段，CSV 可增加同名列：

```json
{
  "source_message_id": "reply-2",
  "reply_to_source_message_id": "origin-1",
  "sender_name": "测试用户",
  "sent_at": "2026-08-23 10:00:00",
  "content_text": "回复原消息"
}
```

目标 ID 限 1–128 个 ASCII 字母、数字、下划线或短横线，不能等于消息自身源 ID。字段必须位于标准化导入消息顶层；不会从嵌套微博分享对象提取。

- 入库时在同一事务保存引用关系，目标未入库也保留目标源 ID。
- 目标后来入库，下一次定位即可按源 ID 找到，不要求先入原文再入回复。
- 旧库启动迁移时，只回填原始数据中明确保留上述标准化字段和消息字段的记录；缺少证据的旧消息保持文字匹配。
- 同范围同源 ID 出现多个记录时返回歧义，不任意选择。

## 数据与安全边界

`message_references` 保存引用消息、目标本地 ID/源 ID、来源方法和时间。`message_reference_dismissals` 保存明确解除标记；建表兼容旧库，不修改原消息正文。

所有查询、候选、确认和解除均校验账号、群与删除状态。目标不得是自身或时间晚于回复的消息；可靠 ID/人工确认允许同秒，文字匹配仍只考虑严格更早的消息。

目标软删除后不会从普通视图泄露正文，也不会退回到另一条同文消息；恢复原目标后可继续定位。目标彻底删除时人工关联保留为不可用，不自动关联到其他消息。引用消息彻底删除时关联元数据随之清理。所有关系查询保持本地，不发出微博请求。

新增接口为 `GET /api/messages/{id}/reference-candidates`、`PUT /api/messages/{id}/reference`、`DELETE /api/messages/{id}/reference`；保存/解除必须显式确认。已有 `quote-context` 返回的 `match_method` 扩展为 `full_text`、`manual`、`source_id`，其他隔离与有界窗口契约保持不变。

## 验证记录

先观察永久引用端点缺失、标准化导入仍走文字匹配、解除关系后被历史回填重新添加等业务失败，再实现。覆盖同文消歧、同秒和晚入库目标、软删/恢复、彻底删除、源 ID 重复、账号/群隔离、忽略微博分享回复字段和迁移幂等。已有引用文字匹配与超时/迟到隔离回归保留。
